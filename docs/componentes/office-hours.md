# Skill `office-hours`

**Propósito:** aclarar una idea y decidir qué versión construir antes de escribir código.

- **Cuándo se activa:** solo cuando el usuario la invoca con `/office-hours` (tiene `disable-model-invocation: true`), ante una idea nueva de app, negocio o feature grande.
- **Entradas:** contexto del proyecto y respuestas del usuario a preguntas de una en una.
- **Salida:** documento de diseño con premisas, alternativas, recomendación y una tarea concreta.
- **Ejemplo:** `/office-hours` para explorar una idea de herramienta personal.
- **Límites:** no escribe código ni scaffoldea; espera que el usuario elija un enfoque.
