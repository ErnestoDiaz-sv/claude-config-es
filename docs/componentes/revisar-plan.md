# Skill `revisar-plan`

**Propósito:** encontrar supuestos, riesgos y problemas de alcance en un plan antes de programar.

- **Cuándo se activa:** hay un plan escrito que necesita revisión o se pide `/revisar-plan`.
- **Entradas:** plan, repositorio y decisiones de alcance del usuario.
- **Salida:** plan revisado con premisas, alternativas, checklist y resumen de revisión.
- **Ejemplo:** `/revisar-plan` antes de implementar una feature no trivial.
- **Límites:** no modifica código; presenta hallazgos de a uno y espera decisiones del usuario.
