# Agente `explorador`

**Propósito:** buscar, leer y resumir información mecánica.

- **Cuándo se usa:** localizar código, listar elementos o resumir varios archivos.
- **Entradas:** tarea de reconocimiento y rutas pertinentes.
- **Salida:** respuesta breve con rutas y líneas como evidencia.
- **Ejemplo:** pedir que encuentre dónde se configura una función.
- **Límites:** solo lectura; no decide ni edita, y evita directorios enumerados en su archivo.
