# Reglas para agentes que trabajen en este repo

- Documentación en español; código, comentarios de scripts, nombres de archivo y CI en inglés.
- Antes de decir que algo está listo, correr `scripts/check.sh` y reportar el resultado real.
- Cambios chicos y puntuales. No agregar dependencias ni skills nuevas sin que se pidan.
- No cambiar el comportamiento de `skills/`, `agents/` o `hooks/` como parte de un cambio de documentación.
- Toda afirmación en `docs/` tiene que estar respaldada por el archivo del componente. Sin cifras de ahorro o rendimiento: no hay mediciones.
- Nunca commitear `.env`, claves ni rutas o datos personales.
- Ver `CONTRIBUTING.md` para el flujo de aportes.
