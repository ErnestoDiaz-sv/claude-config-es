# Reglas del proyecto

## Antes de cambiar código

- Leé las instrucciones y el código relevante del repositorio.
- Reutilizá primero patrones existentes, biblioteca estándar y capacidades de la plataforma.
- Si el objetivo o el alcance no están claros, preguntá antes de implementar.

## Implementación y verificación

- Hacé cambios acotados a la tarea aprobada.
- Agregá o actualizá pruebas para el comportamiento que cambies.
- Ejecutá la suite completa y reportá el resultado real.
- No afirmes que algo funciona si no lo verificaste.

## Seguridad y comunicación

- No incluyas credenciales ni datos sensibles en el código, ejemplos o logs.
- No hagas commit, push ni despliegue salvo que se solicite.
- Explicá primero en lenguaje simple y enumerá los archivos modificados.
